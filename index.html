Install

You need Python 3.11+, pipx and Chrome. On Windows, use the python.org installer, not the Microsoft Store build.

No pipx yet? Install it and put it on your PATH, then open a new terminal:

# Windows (python.org or Microsoft Store Python)
python -m pip install --user pipx
python -m pipx ensurepath

# macOS
brew install pipx
pipx ensurepath

Then:

pipx install https://jaaaayden.github.io/pnt-dist/pokernow_tracker-0.1.3-py3-none-any.whl
pnt setup

Then in Chrome open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder pnt setup printed. Open http://127.0.0.1:52000 for everything else.

Update

pnt update

Always pnt update, never pipx upgrade: pipx reinstalls the version you first installed. The front page and the HUD say when there is one; pnt --version shows yours.

Already installed?

Does installing again replace the old version?
No: pipx install says "already installed" and changes nothing. Run pnt update, which replaces the old version in place; there is nothing to uninstall first. Ignore pipx's hint to run pipx upgrade: that goes back to the version you first installed.
pnt update fails
Installed before November 2026: run pnt update --from https://jaaaayden.github.io/pnt-dist/pokernow_tracker-0.1.3-py3-none-any.whl once. Plain pnt update works after that.
Will I lose my hands?
No. They are in a pokernow.sqlite file outside the install, which updates never touch; pnt where shows where.
Do I reload the Chrome extension?
It reloads itself within a minute. HUD still looks old? Click its reload arrow at chrome://extensions.
Remove it completely
pnt service uninstall
pipx uninstall pokernow-tracker
Then remove the extension at chrome://extensions. The database file stays until you delete it.
